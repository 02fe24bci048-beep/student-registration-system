# Student Registration System

A simple Node.js + Express Student Registration System inspired by a university portal layout.

## Features

- Student registration
- Student login
- Dashboard/home page
- Course table
- Search courses
- Course registration button
- Responsive design
- Ready for GitHub and Render

## Run locally

```powershell
npm install
npm start
```

Open:

http://localhost:3000

### Important

This starter project uses in-memory data. Registered users are reset when the server restarts. For permanent data, connect the application to MySQL/TiDB Cloud in a later step.
